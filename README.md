
# 대장암에서 미세부수체 불안정성(MSI)과 돌연변이 수의 관계 분석

TCGA 대장암 유전체 데이터를 활용하여 **미세부수체 불안정성(MSI)과 암세포의 돌연변이 수 사이의 관계**를 분석하고, 그 결과를 대화형 그래프로 확인할 수 있는 웹 애플리케이션입니다.

## 1. 프로젝트 개요

### 분석 목적

DNA는 세포가 유전 정보를 저장하는 물질입니다. 세포가 분열할 때 DNA가 복제되는데, 이 과정에서 작은 오류가 발생할 수 있습니다. 우리 몸에는 이러한 오류를 찾아 수정하는 기능이 있습니다.

이 기능이 제대로 작동하지 않으면 DNA의 특정 반복 구간에서 변화가 많이 나타날 수 있습니다. 이러한 현상을 **미세부수체 불안정성(MSI, Microsatellite Instability)**이라고 합니다.

이 프로젝트에서는 대장암 환자의 유전체 데이터를 이용해 **MSI 정도와 암세포에서 발견된 돌연변이 수 사이에 어떤 관계가 있는지** 살펴봅니다.

### 주요 분석 지표

- **MSIsensor Score**: 정상 세포와 암세포의 DNA를 비교하여, 단편 반복 서열 중 길이 변화가 관찰된 구간의 비율을 점수로 나타낸 지표입니다.
  - 3.5 이상: MSI-H (MSI가 높은 상태)
  - 3.5 미만: MSS (MSI가 낮거나 뚜렷하게 확인되지 않는 상태)

- **MSI MANTIS Score**: 정상 세포와 암세포의 DNA에서 단편 반복 서열의 길이 분포가 얼마나 다른지를 종합하여 MSI 정도를 점수화한 지표입니다.
  - 0.4 이상: MSI-H (MSI가 높은 상태)
  - 0.4 미만: MSS (MSI가 낮거나 뚜렷하게 확인되지 않는 상태)

- **Mutation Count**: 암세포에서 확인된 돌연변이의 수입니다. 

## 2. 데이터 설명

분석 파일인 `processed_colorectal_msi.csv`는 원본 데이터에서 분석에 필요한 6개 항목을 선별해 정리한 자료입니다.

| 데이터 항목 | 설명 |
|---|---|
| `Tumor Disease Anatomic Site` | 암이 처음 발생한 위치 (예: 대장, 직장) |
| `MSIsensor Score` | MSIsensor로 측정한 MSI 점수 |
| `MSIsensor 기반 MSI 상태` | MSIsensor 점수 기준으로 구분한 MSI 상태 |
| `MSI MANTIS Score` | MANTIS로 측정한 MSI 점수 |
| `MANTIS 기반 MSI 상태` | MANTIS 점수 기준으로 구분한 MSI 상태 |
| `Mutation Count` | 돌연변이 수 |

## 3. 데이터 출처

- **원자료:** The Cancer Genome Atlas (TCGA), Colorectal Adenocarcinoma (PanCancer Atlas)
- **데이터 제공·탐색 플랫폼:** cBioPortal
- **분석용 데이터:** `processed_colorectal_msi.csv`

## 4. 분석에서 유의할 점

- 이 프로젝트는 MSI 점수와 돌연변이 수 사이의 **관계 및 경향**을 살펴보는 데이터 분석입니다.
- 두 지표 사이에 관계가 관찰되더라도, 그것만으로 MSI가 돌연변이 증가의 직접적인 원인이라고 단정할 수는 없습니다.
- 분석 결과는 사용한 데이터와 변수의 범위 안에서 해석해야 하며, 모든 대장암 환자에게 동일하게 적용된다고 볼 수 없습니다.
- MSI 상태 구분 기준은 사용한 측정 방법에 따라 다르므로 MSIsensor와 MANTIS의 결과를 구분해 해석해야 합니다.
